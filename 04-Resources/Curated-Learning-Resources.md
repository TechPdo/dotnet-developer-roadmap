# 📖 Curated Learning Resources

Every link below was checked before being added. Three kinds of sources, on purpose:
1. **Microsoft Learn** — the authoritative, always-updated source for how a feature actually works
2. **Verified YouTube channels** — well-established, reputable .NET educators (official Microsoft channels + widely-recognized independent creators)
3. **Other authentic resources** — official project docs, free interactive practice sites, and well-regarded books

Organized to mirror this course's structure — jump to the section matching where you are.

## 📺 Verified YouTube Channels

**Official Microsoft channels**
- **.NET (official Microsoft team channel)** — releases, deep dives, conference talks — https://www.youtube.com/@dotnet
- **Microsoft Developer** — broader Microsoft dev content including Azure/.NET — https://www.youtube.com/@MicrosoftDeveloper

**Well-established independent .NET educators**
- **Nick Chapsas** — sharp, up-to-date C#/.NET content, performance, testing, new language features — https://www.youtube.com/@nickchapsas
- **Milan Jovanović** — architecture, Clean Architecture, CQRS/MediatR, DDD, distributed systems — https://www.youtube.com/@MilanJovanovicTech
- **IAmTimCorey** — long-form, thorough beginner-to-intermediate C#/.NET tutorials — https://www.youtube.com/@IAmTimCorey
- **Programming with Mosh** — beginner-friendly C#, SQL, and general programming courses — https://www.youtube.com/@programmingwithmosh

**General full-stack / broad coverage (verified, high-quality)**
- **freeCodeCamp.org** — full-length free courses, including several complete ASP.NET Core + EF Core courses — https://www.youtube.com/@freecodecamp

**Frontend (React/Angular/TypeScript)**
- Use the *official* React and Angular documentation sites below as your primary source — both frameworks' docs now include excellent built-in interactive tutorials, which is the most authentic and version-accurate way to learn them.

> ⚠️ A note on YouTube generally: channel content and quality can change over time, and a great video from a couple of .NET versions ago may show outdated APIs. Cross-check anything version-specific (Minimal APIs, Identity token endpoints, EF Core syntax) against the Microsoft Learn link for that topic.

| 3. Understand .NET | `01-Beginner/02-DotNet-Basics.md` |
| 4. Master ASP.NET Core | `01-Beginner/03-AspNetCore-Intro.md` → `03-Advanced/02-AspNetCore-Advanced.md` |
| 5. Master Databases (SQL) | `01-Beginner/05-EFCore-Basics.md` (SQL Fundamentals section) |
| 6. Entity Framework Core | `01-Beginner/05-EFCore-Basics.md` → `03-Advanced/04-EFCore-Advanced-Performance.md` |
| 7. Build Real REST APIs | `01-Beginner/04-WebAPI-Basics.md` → `03-Advanced/03-WebAPI-Advanced.md` |
| 8. Authentication & Security | `02-Intermediate/07-Security-Identity-Basics.md` → `03-Advanced/07-Security-Advanced.md`, `08-Identity-RBAC-Advanced.md` |
| 9. Testing | `02-Intermediate/03-WebAPI-Intermediate.md` (Unit/Integration/API Testing sections) |
| 10. Frontend Basics | `01-Beginner/06-Frontend-Basics.md` |
| 11. Advanced Backend Skills | `02-Intermediate/02-AspNetCore-Intermediate.md`, `03-Advanced/02-AspNetCore-Advanced.md`, `10-Observability-Logging-Advanced.md` |

This course additionally goes beyond that roadmap with dedicated **CQRS/MediatR**, **multi-tenant RBAC**, and an **AI track from basics through agentic systems (MCP)** — reflecting where .NET development is heading, not just where it's been.
